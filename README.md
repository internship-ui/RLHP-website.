# Rural Literacy & Health Programme (RLHP) Website

Official website for the **Rural Literacy & Health Programme (RLHP)**, Mysore, Karnataka.

RLHP has been actively committed to grassroots empowerment, child rights, education, women empowerment, health camps, and community development across Karnataka for over 42 years.

---

## 🌟 Key Features
- **Modern Responsive Design**: Accessible and mobile-friendly interface for desktop, tablet, and mobile devices.
- **Programs & Initiatives**: Showcasing Child Rights, Women Empowerment, Health & Nutrition, and Youth Development.
- **Interactive Modules**: Verified impact stories, media coverage gallery, and pledge submission features.
- **Transparency & Accountability**: Statutory compliance, FCRA details, and audited annual reports.

---

## 🚀 Getting Started Locally

### Prerequisites
- Modern web browser (Chrome, Edge, Firefox, Safari)
- [Node.js](https://nodejs.org/) (optional, for local preview server)

### Running Locally

1. **Option 1: Using the built-in Node.js server**
   ```bash
   node server.js
   ```
   Open your browser and navigate to: [http://localhost:3000](http://localhost:3000)

2. **Option 2: Direct file opening**
   Simply open `index.html` in your favorite web browser.
